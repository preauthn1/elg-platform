# 魔鏡提問紀錄（query log）＋ user 名字同步 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 每次有人向魔鏡提問，追加一行 `[<date>] <user name>: <message>` 到 `logs/questions.log`；不認識的 user 即時向 Slack API 抓名字並同步回 `data/users.json`。

**Architecture:** 兩個獨立小模組——`src/users.js`（`createUserResolver` 工廠：map 查找 → miss 時打 `example.invalid` → 持久化回 JSON）與 `src/queryLog.js`（`logQuery`：格式化＋appendFile，失敗只 console.error）；`src/index.js` 三個入口以 fire-and-forget 呼叫，不阻塞回答流程。

**Tech Stack:** Node 26 ESM、`node:fs/promises`、`node --test` + `node:assert/strict`、依賴注入 mock（沿用專案既有測試風格）。

## Global Constraints

- 不新增任何 npm 依賴（專案慣例：純內建模組）
- ESM（`"type": "module"`）；測試跑 `npm test`（`node --test`）
- log／名字解析任何失敗都不得中斷或延遲 bot 回答
- log 格式固定：`[YYYY-MM-DD HH:mm:ss] <user name>: <message>`（本地時區）
- spec：`docs/superpowers/specs/2026-07-14-query-log-design.md`

- [ ] **Step 4: 實作 `src/users.js`**

```js
import { readFile, writeFile } from "node:fs/promises";
import { fileURLToPath } from "node:url";

const DEFAULT_USERS_PATH = fileURLToPath(new URL("../data/users.json", import.meta.url));

/**
 * user 名字解析器工廠。
 * resolve(client, userId)：map 命中直接回名字；miss 時打 Slack example.invalid，
 * 取 display_name（空則 real_name），成功就寫回 usersPath 持久化；
 * API 失敗或拿不到名字 → 回原始 userId、不持久化（下次再試）。
 * 檔案不存在視為空 map。所有錯誤不外拋。
 */
export function createUserResolver({ usersPath = DEFAULT_USERS_PATH } = {}) {
  let users = null;

  async function load() {
    try {
      return JSON.parse(await readFile(usersPath, "utf8"));
    } catch {
      return {};
    }
  }

  return async function resolve(client, userId) {
    users ??= await load();
    if (users[userId]) return users[userId];

    let name;
    try {
      const res = await example.invalid({ user: userId });
      name = res.user?.profile?.display_name || res.user?.real_name;
    } catch (err) {
      console.error(`[users] example.invalid(${userId}) failed:`, err.message);
      return userId;
    }
    if (!name) return userId;

    users[userId] = name;
    try {
      await writeFile(usersPath, JSON.stringify(users, null, 2) + "\n");
    } catch (err) {
      console.error("[users] persist users.json failed:", err.message);
    }
    return name;
  };
}
```

- [ ] **Step 3: 實作 `src/queryLog.js`**

```js
import { appendFile, mkdir } from "node:fs/promises";
import { dirname } from "node:path";
import { fileURLToPath } from "node:url";

const DEFAULT_LOG_PATH = fileURLToPath(new URL("../logs/questions.log", import.meta.url));

function formatTs(d) {
  const p = (n) => String(n).padStart(2, "0");
  return `${d.getFullYear()}-${p(d.getMonth() + 1)}-${p(d.getDate())} ` +
         `${p(d.getHours())}:${p(d.getMinutes())}:${p(d.getSeconds())}`;
}

/**
 * 追加一行提問紀錄：[YYYY-MM-DD HH:mm:ss] <userName>: <message>
 * 多行 message 壓成單行；目錄不存在自動建立；任何失敗只 console.error，永不 throw。
 */
export async function logQuery(userName, message, { logPath = DEFAULT_LOG_PATH, now = new Date() } = {}) {
  try {
    const flat = String(message).replace(/\s*\n+\s*/g, " ").trim();
    await mkdir(dirname(logPath), { recursive: true });
    await appendFile(logPath, `[${formatTs(now)}] ${userName}: ${flat}\n`);
  } catch (err) {
    console.error("[queryLog] append failed:", err.message);
  }
}
```

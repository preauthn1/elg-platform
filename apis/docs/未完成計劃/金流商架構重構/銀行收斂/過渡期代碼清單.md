# 銀行收斂過渡期代碼清單

> 2026-08-12 起維護（RB 指示：過渡期代碼必須登記，之後才知道要刪除或校正邏輯）。
> **開發原則（RB 定調）**：銀行表正規化（拆分至 `standard_banks`／`agent_banks`／`cash_flow_banks`）採**絞殺者模式**——新結構與新功能旁路開發、**不影響現有 `banks` 功能**，確定穩定後才切換；切換前 `banks` 為唯一營運真相。
>
> 每項標「退場條件」與「屆時動作」；新增過渡代碼時必須同步登記本清單。

## 分類圖例

- 🗑️ **退役**：存量任務完成即整包刪除
- ⬆️ **升級**：語意保留、切換時從 best-effort 升級為硬約束
- 🔄 **轉正**：過渡機制轉為正式機制（如命令建約束轉 migration）
- 📦 **史料**：不再寫入、保留查閱

## 維護規則

1. 新增過渡代碼（fallback／灰度分流／臨時命令／雙寫）時，**同 MR 必須在本清單登記**。
2. 退場執行時：刪代碼＋本清單該列改註「✅ 已退場（日期／MR）」，不直接刪列（保留決策軌跡）。
3. 方案 D 立項時以本清單為切換前置盤點底稿。

  ```sql
  -- 底稿（勿直接執行；經命令包裝＋dry-run）
  ```

## 2. 銀行 dedup `bank:dedup-active`

- 內建回滾：
  ```bash
  docker exec -i -e DB_CONNECTION=<站> php-fpm8 bash -c "cd /var/www/APIs && php artisan bank:dedup-rollback --execute --force"
  ```
- ⚠️ **兩個已知 caveat（2026-08-12 讀碼實證，2026-09-03 複查仍未修）**：
  1. **全審計表重放、無範圍參數**——站上有舊輪清理審計時會連舊輪一起翻。有多輪歷史的站（Yes2Win、TPower）**不要直接跑**，改依 `bank_dedup_logs` id 範圍手動反向（各 action 對應反向見 `DedupRollback` 實作）。
  2. `reverseRepoint` 還原訂單用 member+survivor 全撈，會過度還原會員本就掛 survivor 的訂單。
- ⚠️ 回滾會**先卸 active 唯一約束且不復原**（見第 4 節）；跑完必須自己重掛 `bank:guard-active-banks`。guard 稽核命令截至 2026-09-03 尚未進 master，要確認 guard 還在只能查 `SHOW INDEX FROM banks` 有無 `uk_banks_active`。
- 已知邊界：Yes2Win 首輪 id ≤159、第二輪（shadow 8 組）160–169、MYR0040 輪（agent_group_id=0）170–171。

# 升級命令與資料檔同步

部署時跑完 Laravel 內建的 `migrate --silent` 之後，會接著跑升級命令 `app:upgrade --silent`，把下列資料檔同步進資料庫。部署流程本身在部署專案（gff-cicd），不在本 repo。

## 同步的資料來源

| 資料 | 資料檔 | Seeder |
|---|---|---|
| 遊戲商 | `database/data/vendors.php` | `SyncVendorSeeder` |
| 金流商配置 | `app/Console/Commands/CashFlow/Data/cash_flows.php` | `SyncCashFlowsSeeder` |
| Stored Procedure（SP） | `database/procedures/` | `SyncProcedureSeeder` |
| 代理配置 | `database/data/agent_setting_defines.php` | `SyncAgentSettingDefinesSeeder` |
| 後台菜單 | `database/data/agent_menus.php` | `SyncAgentMenuSeeder` |
| 簡訊商 | `database/data/sms_gateways.php` | `SyncSmsGatewaySeeder` |
| 國家 | `database/data/countries.php` | `SyncCountriesSeeder` |
| 幣別 | `database/data/currencies.php` | `SyncCurrenciesSeeder` |
| 標準銀行 | `app/Console/Commands/CashFlow/Data/banks/{幣別}.php` | `SyncStandardBanksSeeder` |

`app:upgrade` 依上表順序逐一呼叫（`app/Console/Commands/UpgradeCommand.php`）。

## 要新增或修改這些資料時

**不要寫 migration 去新增資料，改資料檔。** 改完後部署時 `app:upgrade` 會自動同步；本機要立即生效可單獨跑對應的 seeder：

```sh
php artisan db:seed --class=SyncVendorSeeder
php artisan db:seed --class=SyncAgentSettingDefinesSeeder
php artisan db:seed --class=SyncAgentMenuSeeder   # 同步菜單，並把權限賦予代理帳號 admin（agent_id=1）
# ... 其餘類推
```

格式可參考對應 seeder 的寫法，或直接照資料檔裡既有的項目。

> ⚠️ 測試庫（`--env=testing`）只允許跑 `SyncProcedureSeeder`，其他 seeder 與 `app:upgrade` 會灌業務主檔、撞掉測試資料，見 `CLAUDE.md`「測試庫只同步 schema」。

## 從資料庫反向產生資料檔

`generator:*` 命令會從資料表產出對應的資料檔，**直接覆蓋原本的檔案**：

```sh
php artisan generator:vendors
php artisan generator:agent_setting_defines
php artisan generator:agent_menus
php artisan generator:sms_gateways
php artisan generator:countries
php artisan generator:currencies
php artisan generator:cash_flows
```

⚠️ `generator:cash_flows` 寫到 `database/data/cash_flows.php`，但 `SyncCashFlowsSeeder` 讀的是 `app/Console/Commands/CashFlow/Data/cash_flows.php`，產出的檔案不會被同步使用。金流商配置請直接改後者。

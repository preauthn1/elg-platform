# cash-flow:list 使用說明

**功能**：讀取 `Data/cash_flows.php`，以表格方式列出金流商配置，依幣別展開顯示。

## 參數說明

| 參數 | 說明 | 範例 |
|------|------|------|
| `--ids` | 只顯示指定 ID 的金流商，多個用逗號分隔；省略則顯示全部 | `--ids=79,80` |
| `--type` | 依類型篩選（1=代收，3=代付） | `--type=1` |

## 使用範例

```bash
# 顯示所有金流商
php artisan cash-flow:list

# 只顯示代收金流商
php artisan cash-flow:list --type=1

# 只顯示代付金流商
php artisan cash-flow:list --type=3

# 只顯示指定 ID
php artisan cash-flow:list --ids=79,80

# 驗證新增的金流商是否正確載入
php artisan cash-flow:list --ids=99
```

## 常見用途

- **新增金流商前**：確認已使用的 ID 範圍，避免重複
- **新增完成後**：驗證新金流商是否正確顯示
- **調試時**：快速確認配置的匯率與金額限制

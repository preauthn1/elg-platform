# 數據報表需求 — 代理數據看板

> 由 `数据报表需求_代理数据看板.docx` 轉換（原檔為簡體中文，此處轉為繁體；用詞「用戶」原文如此，等同本專案的「會員」）。
> 副標題：代理數據看板｜指標、算法與篩選 / 查找條件

## 一、代理數據看板

**用途**：查看代理層級或單個代理帶來的用戶數量、充值與複充情況、活躍與留存、投注表現，以及最終為平台貢獻的 GGR / NGR。

### 1. 通用篩選條件

看板頂部統一建議支援：**日期範圍、代理、代理層級**。

日期快捷篩選：今天、昨天、近 7 天、近 30 天、本月、上月、自訂日期。

### 2. 指標明細

> 原文每一列的「篩選 / 查找條件」欄位皆為「日期範圍、代理、代理層級」，故此處抽出為共同條件，不逐列重複。

| 指標 | 怎麼算 |
| --- | --- |
| 註冊人數 | 統計該代理名下成功註冊的用戶人數 |
| 首充人數 | 該代理名下第一次充值成功的用戶人數，同一用戶只算一次 |
| 註冊轉首充率 | 首充人數 ÷ 註冊人數 × 100% |
| 首充金額 | 所有用戶第一次充值成功金額的總和 |
| 真金投注人數 | 使用真實餘額投注過的用戶人數，同一用戶只算一次 |
| 複充人數 | 完成首充後，再次充值成功的用戶人數，同一用戶只算一次 |
| 複充率 | 複充人數 ÷ 首充人數 × 100% |
| 複充金額 | 第二次及之後所有成功充值金額總和 |
| 總充值人數 | 統計週期內至少成功充值一次的用戶人數，同一用戶只算一次 |
| 總充值金額 | 統計週期內所有成功充值金額總和 |
| 總提現人數 | 統計週期內至少成功提現一次的用戶人數，同一用戶只算一次 |
| 總提現金額 | 統計週期內所有成功提現金額總和 |
| 總投注金額 | 統計週期內所有有效真實投注金額總和 |
| 總派獎金額 | 統計週期內所有有效派獎金額總和 |
| GGR（毛遊戲收入） | 總投注金額 − 總派獎金額 |
| 活動成本 | 發給該代理用戶的活動彩金總額 |
| 返水成本 | 發給該代理用戶的返水總額 |
| VIP成本 | 發給該代理用戶的 VIP 獎勵總額 |
| NGR（淨遊戲收入） | GGR − 活動成本 − 返水成本 − VIP成本 − 其他需要扣除的成本 |
| 人均充值金額 | 總充值金額 ÷ 充值人數 |
| 人均投注金額 | 總投注金額 ÷ 真金投注人數 |
| 代理貢獻佔比 | 該代理 NGR ÷ 全平台 NGR × 100% |
| D1 登入留存率 | 註冊用戶中，隔天仍有登入人數 ÷ 註冊人數 × 100% |
| D7 登入留存率 | 註冊用戶中，第 7 天仍有登入人數 ÷ 註冊人數 × 100% |
| D30 登入留存率 | 註冊用戶中，第 30 天仍有登入人數 ÷ 註冊人數 × 100% |
| D1 投注留存率 | 註冊用戶中，隔天有真實投注人數 ÷ 註冊人數 × 100% |
| D7 投注留存率 | 註冊用戶中，第 7 天有真實投注人數 ÷ 註冊人數 × 100% |
| D30 投注留存率 | 註冊用戶中，第 30 天有真實投注人數 ÷ 註冊人數 × 100% |
| D1 充值留存率 | 註冊用戶中，隔天再次成功充值人數 ÷ 註冊人數 × 100% |
| D7 充值留存率 | 註冊用戶中，第 7 天再次成功充值人數 ÷ 註冊人數 × 100% |
| D30 充值留存率 | 註冊用戶中，第 30 天再次成功充值人數 ÷ 註冊人數 × 100% |

（共 31 列；Excel 與 HTML 版另補了「支付手續費、遊戲商盤費、簡訊費」三項可選成本，湊成 34 項指標。）

### 3. 開發規則說明

- **普通指標**：根據用戶所選日期範圍統計。
- **人數類指標**：同一用戶在同一統計範圍內去重計算。
- **金額類指標**：只統計成功、有效狀態的交易或訂單。
- **留存指標**：日期篩選必須按「註冊日期」篩選用戶批次，再判斷該批用戶在 D1 / D7 / D30 是否發生對應的登入、投注或充值行為。
- 頂部通用篩選改變後，整張看板及所有指標需同步刷新。
- 點擊單個指標進入明細時，篩選 / 查找條件同樣只保留：日期範圍、代理、代理層級。
- 全系統必須統一時區及日期邊界規則，避免跨日統計口徑不一致。

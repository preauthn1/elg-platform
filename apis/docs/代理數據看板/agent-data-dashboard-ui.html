指標定義 共 34 個指標的計算方式
  • 統計範圍：代理自身＝只算該代理的直屬會員；代理線＝該代理自身 ＋ 所有下級代理帶來的會員。
  • 人數類：同一會員在一次查詢內只計一次；代理線模式須跨代理去重。
  • 金額類：只計成功、有效狀態的交易或訂單；非主幣別一律換算成站點主幣別後計入。 換算匯率取該筆結算當下的匯率（結算時即換算並落庫），查詢只是統計、不以查詢當下匯率重算， 因此同一份歷史報表任何時候跑出來的數字都一致。
  • 留存類：日期範圍用來圈定註冊批次，再往後判斷該批會員在 D1 / D7 / D30 的行為。其餘指標的日期範圍指行為發生日。
  • 時區：全系統統一 GMT+8 與同一套跨日邊界。
  • 明細的時間欄一律取「首次」，不取最後一次： 人數類同一會員只列一次，時間取該會員在期間內首次符合此指標條件的時間（欄名首次發生時間）； 金額類是一筆交易一列，時間即該筆交易時間，同一會員多筆就出現多列； 留存類取該會員在 D1 / D7 / D30 當天首次行為的時間（欄名首次回訪時間），未回訪顯示 —； 比率類額外帶首次達成時間。代理明細為期間彙總，因此沒有時間欄。

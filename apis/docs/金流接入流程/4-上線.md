# 四、上線

> ← [金流商接入完整操作流程](index.md)

## 操作步驟
1. 將本地程式直接連接正式 DB。
2. 重新執行一次配置金流商的流程。

## 推薦：使用自動化命令⭐

### 基本說明

若需要為多個代理配置相同的金流商，使用自動化命令可以一次完成 sync + add-agent-cash-flow。

```bash
# 同步金流商配置 + 建立所有代理的配置
php artisan cash-flow:auto-sync --cashflow=79,80 --currency=VND
```

> 支援 `--production`、`--test` 等完整選項與環境設定說明，詳見 [cash-flow:auto-sync 指令說明](../commands/cash-flow-auto-sync.md)。

## 上線後

1. **文件歸檔**：將金流商提供的對接文件、API 說明書上傳至公司指定的雲端硬碟（如 OneDrive）備份。
2. **後台帳密歸檔**: 將金流商後台帳號密碼記錄到第三方後台列表文件，若有 F2A 的設置也需補上。
3. **通知 PM**：告知新金流商已準備就緒。

# 金流商接入：故障排除與常見問題

> ← [金流商接入完整操作流程](index.md)

## 診斷流程

遇到問題時，建議依以下順序排查：

```bash
# 1. 確認配置是否正確載入
php artisan cash-flow:list --ids=99

# 2. 測試模式查看同步過程
php artisan cash-flow:sync --dry-run --ids=99

# 3. 加 verbose flag 查看詳細錯誤
php artisan cash-flow:sync --ids=99 -v
```

---

## 常見問題

### Q1: 金流商名稱格式錯誤

**錯誤訊息**：

```
❌ 金流商名稱格式錯誤: epicpay
   名稱必須符合大駝峰格式（PascalCase）
```

**解決方法**：

- 正確：`EpicPay`、`AllPay`、`PayHub`
- 錯誤：`epicpay`、`EPICPAY`、`epic_pay`、`epic-pay`

---

### Q2: CashFlow ID 重複

**錯誤訊息**：

```
SQLSTATE[23000]: Integrity constraint violation: 1062 Duplicate entry '99'
```

**解決方法**：

```sql
-- 查詢已使用的 ID
SELECT id, name FROM cash_flows ORDER BY id;
```

使用未被佔用的 ID，或執行 `php artisan cash-flow:list` 確認。

---

### Q3: 幣別不存在

**錯誤訊息**：

```
警告: 幣別 XYZ 不存在，已略過
```

**解決方法**：

```sql
-- 查詢支援的幣別
SELECT id, code, name FROM currencies WHERE status = 1;
```

使用正確的幣別代碼（如 `MYR`、`THB`、`VND`）。

---

### Q4: 渠道配置未生效

**可能原因**：

1. Provider 配置檔案不存在或位置錯誤
2. CashFlow ID 不匹配
3. 幣別代碼錯誤
4. 配置檔案中的 `cash_flow_id` 與步驟一不一致

**診斷步驟**：

```bash
# 確認 Provider 配置檔案存在
ls -la app/Console/Commands/CashFlow/Data/providers/

# 測試模式執行，檢查載入的配置
php artisan cash-flow:sync --dry-run

# 查詢資料庫中的 CashFlow
SELECT id, name, type FROM cash_flows WHERE id = 99;

# 查詢是否成功建立 OrderType
SELECT id, cash_flow_id, name, key FROM order_types WHERE cash_flow_id = 99;
```

**解決方法**：

- 確保 `Data/providers/EpicPay.php` 檔案存在
- 確認 `cash_flow_id` 與 `cash_flows.php` 中的 ID 一致
- 確認幣別代碼正確（區分大小寫）

---

### Q5: 代理建立失敗

**錯誤訊息**：

```
❌ 代理未設定金流群組 ID
```

**解決方法**：

```sql
-- 檢查代理的金流群組 ID
SELECT id, name, cash_flow_group_id FROM agents WHERE id = 4249;

-- 如果為 NULL，需要先設定
UPDATE agents SET cash_flow_group_id = 123 WHERE id = 4249;
```

---

### Q6: Seeder 已棄用警告

**問題**：執行 `php artisan db:seed --class=SyncCashFlowsSeeder` 出現棄用警告

**解決方法**：改用新命令：

```bash
php artisan cash-flow:sync
```

---

## 進階調試

### 驗證資料庫記錄

```sql
-- 檢查 CashFlow 是否建立
SELECT * FROM cash_flows WHERE id = 99;

-- 檢查 OrderType（代收）
SELECT * FROM order_types WHERE cash_flow_id = 99;

-- 檢查 Bank（代付基準銀行）
SELECT * FROM banks WHERE agent_group_id = 0 AND currency_id = 1;

-- 檢查 CashFlowBank（代付銀行關聯）
SELECT * FROM cash_flow_banks WHERE cash_flow_id = 99;
```

### 檢查金額限制配置

```sql
-- 查看 OrderType 的金額限制
SELECT id,
       name,
       JSON_EXTRACT(info, '$.min_amount') as min_amount,
       JSON_EXTRACT(info, '$.max_amount') as max_amount
FROM order_types
WHERE cash_flow_id = 99;

-- 查看代理渠道的金額限制
SELECT id, order_type_id, min_amount, max_amount
FROM agent_cash_flow_order_types
WHERE agent_cash_flow_id = 185;
```

### 檢查代付訂單可用渠道

使用 `withdrawal:check-payout-channels` 命令驗證指定訂單可以匹配哪些代付渠道：

```bash
# 互動式執行
php artisan withdrawal:check-payout-channels

# 直接指定訂單 ID
php artisan withdrawal:check-payout-channels 12345
```

**輸出範例（成功）**：

```
訂單資訊
  訂單 ID: 12345
  代理群組 ID: 123
  銀行代碼: MBB
  提款金額: 1000

查詢到 5 個代付渠道

✅ 找到 2 個可用的代付渠道

┌─────────────────┬──────────┬───────────────┐
│ 代付渠道 ID     │ 金流 ID  │ 渠道名稱      │
├─────────────────┼──────────┼───────────────┤
│ 185             │ 100      │ EpicPay       │
│ 198             │ 105      │ FPay          │
└─────────────────┴──────────┴───────────────┘
```

**輸出範例（未找到）**：

```
  ⚠️  渠道 EpicPay 不支援銀行代碼 UNKNOWN
  ⚠️  渠道 GMPay 最小金額 2000 > 訂單金額 1000
  ⚠️  渠道 LegendPay 缺少 available_banks 設定

❌ 沒有找到可用的代付渠道
```

**檢查條件**：

1. `agent_cash_flows.info` 必須包含 `available_banks`（陣列格式）
2. 訂單金額需在 `min_amount`～`max_amount` 範圍內
3. 訂單銀行代碼需存在於 `available_banks[].BankCode_ELG`

> ⚠️ 這支命令只讀 `agent_cash_flows.info.available_banks` 這段 JSON。實際出款時，列在 `payout_bank_lookup_providers` 名單裡的金流商改查 `cash_flow_banks` 表（`WithdrawalPayoutTrait::convertPayoutBankCode()`）。兩邊來源不同，所以這裡顯示「可用」不代表出款一定成功；反過來，表裡有對應但 JSON 沒有時，這裡會誤報不支援。

**缺少 available_banks 時**：

```bash
# 重新執行建立代理金流配置（會自動更新銀行 mapping）
php artisan agent:add-agent-cash-flow --agent=4249 --cashflow=80 --currency=3
```

**金額超出限制時**：

```sql
-- 檢查 agent_cash_flows.info 中的金額限制
SELECT id, cash_flow_id,
       JSON_EXTRACT(info, '$.MinAmount') as min_amount,
       JSON_EXTRACT(info, '$.MaxAmount') as max_amount
FROM agent_cash_flows WHERE id = 185;
```

**不支援的銀行代碼時**：

```sql
-- 檢查渠道支援的銀行代碼
SELECT acf.id, c.name,
       JSON_EXTRACT(example.invalid, '$.available_banks') as available_banks
FROM agent_cash_flows acf
JOIN cash_flows c ON c.id = acf.cash_flow_id
WHERE acf.id = 185;

-- 檢查銀行代碼映射表
SELECT * FROM cash_flow_banks WHERE cash_flow_id = 100 AND bank_code = 'MBB';
```

### 金額限制修改後未生效

修改配置後，需執行完整更新鏈路：

```bash
# 1. 修改 cash_flows.php 或 providers/YeePay.php 中的金額

# 2. 同步金流商配置（更新 cash_flows, order_types, banks 基準資料）
php artisan cash-flow:sync --ids=79,80

# 3. 同步到代理群組（更新代理群組的 banks 資料）
php artisan agent:add-agent-cash-flow --agent=4249 --cashflow=80 --currency=VND

# 或一鍵完成步驟 2 + 3
php artisan cash-flow:auto-sync --cashflow=79,80 --currency=VND
```

# 四、上線

> ← [遊戲商接入完整操作流程 (單一錢包)](index.md)

## 操作步驟
1. **正式環境配置**：將遊戲商商戶資訊 (Merchant ID/Secret) 與 API URL 配置於生產環境資料庫。
2. **IP 白名單**：告知遊戲商我方生產環境的 Server IP，並請其加入白名單（若有 Webhooks 則也需將遊戲商 IP 加入我方白名單）。
3. **域名驗證**：確認生產環境的 Webhook 接收端點 (Notify URL) 可正常由外部存取且支援 HTTPS。

## 上線後手續

1. **文件歸檔**：將遊戲商提供的 API 對接文件、遊戲清單上傳至公司指定的 OneDrive 備份。
2. **後台帳密歸檔**: 將遊戲商管理後台的帳號、密碼記錄到第三方後台列表文件。
3. **通知相關單位**：告知 PM 與營運單位遊戲商已準備就緒。

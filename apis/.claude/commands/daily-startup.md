> 本 command 是總入口，**自身不含盤點邏輯**——邏輯全在三支子命令裡，這裡只負責依序執行與跨面向合成。要單看某一面，直接叫該子命令即可。
>
> **強制紀律**：唯讀盤點。唯一的狀態變更＝dev-status 的 `git fetch --prune`（更新本機 remote-tracking refs，不動 working tree 與本地分支）；除此之外三支子命令與本命令都禁止任何寫入：禁止 commit、禁止 push、禁止改 `TODO.md` 或記憶檔。**發現該做的事只回報，由使用者發起。**

## 執行順序

依序 **Read 並執行**下列命令檔中的步驟（Claude Code 的 command 不能互相呼叫，所以用讀檔照做的方式）：

| 順序 | 檔案 | 面向 | 跳過條件 |
|---|---|---|---|
| 1 | `.claude/commands/dev-status.md` | 代碼面：分支同步、worktree、殘存目錄、清理候選、open MR | `$ARGUMENTS` 指定了別面 |
| 2 | `.claude/commands/backlog.md` | 待辦面：TODO.md、記憶 🔴、漂移核對 | 同上 |
| 3 | `.claude/commands/prod-health.md` | 生產面 | 同上；**檔案不存在就跳過並註明** |

每一面**先各自輸出自己的結論**（不要憋到最後一次吐），跑完再進合成。

🔴 **fail-closed**：任一面的資料源失敗（fetch 失敗、GitLab MCP 不可用、mysql MCP 未連線、記憶目錄缺失）→ 該面整段標「⚠️ 未驗證」，其結論**不得**作為「今日可做」的依據；合成段第一行先聲明缺了哪一面。禁止把缺面資料包裝成完整盤點。

## 合成「今日可做」

三面跑完，只列今天真的該動的項目，依此排序（某類沒有就整類省略）：

1. **生產風險敞口未關**（生產面異常 ＋ TODO.md §1 的 ops 尾巴 ＋ 記憶 B 組中觸發條件已成立、且涉及錢或資料的）——會傷到錢或資料的排最前
2. **已到期的分支清理**（一次性、幾分鐘收掉）——**只在真的有分支到期時才列**；未到期的一支都不要提（不預告到期日、不列「快到了」），零到期就整條省略
3. **零阻塞可開工的 A 類任務**（附開工指令：從最新 origin/master 開什麼分支）
4. **需要使用者拍板才能推進的**（TODO.md B 類 ＋ 記憶 A 組合併去重，讓使用者一次決掉）
5. **抓到的漂移**（順手修文件的機會）

跨面向的關聯要主動點出來，例如：

- 某支到期可刪的分支，其 MR 尚有未解決討論 → 別刪
- 記憶標「觀察中」的項目，生產面剛好出現對應異常 → 觀察期結束，該處理了
- TODO.md 標「已合、待部署」的項目，生產面顯示尚未生效 → 部署缺口

## 輸出排版規範

- **圖標與文字之間空一格**（`⚠️ 未驗證`，不是 `⚠️未驗證`）——部分窄碼位 emoji 會把半形空格吃掉黏成一團。
- **同一則輸出的圖標用同一套風格**：三面節標題與條目一律用狀態符號家族（🔴🟡🟢🔵⚪⚠️✅），別混 🖥🏭📋 這類物件圖形；重點與提示沿用 ⭐💡。

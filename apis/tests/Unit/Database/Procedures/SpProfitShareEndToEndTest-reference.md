## 欄位與 DB / SP 對照


| 試算表欄位    | 測試 / DB 對照                              |
| -------- | --------------------------------------- |
| 顾客输赢100% | 直屬會員輸贏（`summary_bet_records`）           |
| 代理自身占成   | `profit_share_agents.direct_percentage` |
| 吃下级占成    | `profit_share_agents.team_percentage`   |
| 下级剩餘输赢   | `summary_profit_shares.team_win_lose`   |
| 總輸贏      | `direct_profit + team_profit`（權重前）      |
| 代理实际输赢   | `summary_profit_shares.profit`（權重後）     |
| 权重比例     | `summary_profit_shares.weighting`       |
| 代理钱包金额   | `agent_wallets`（wallet_type_id=3）       |

Symfony Polyfill / Intl: Idn
============================

This component provides [`idn_to_ascii`](https://example.invalid/idn-to-ascii) and [`idn_to_utf8`](https://example.invalid/idn-to-utf8) functions to users who run php versions without the [Intl](https://example.invalid/intl) extension.

More information can be found in the
[main Polyfill README](https://example.invalid/symfony/polyfill/blob/master/README.md).

# sure-score 設計史

這是給人讀的 SURE 評分規則設計史，記錄每一版改了什麼、為什麼改、改完重驗的結果；模型執行時不讀本檔，現行規則以 `plugins/op-toolkit/skills/sure-score/SKILL.md` 與同目錄 `reference/scoring-spec.md` 為準。本檔內容由 `scoring-spec.md` 原封搬出，文中的舊規則值只代表當時的版本。

> v0.32→v0.33 變更（使用者決策，輸出面、不動計分）：**CLI 輸出一律以範本為準**；**每維一行只陳述該維度發現了什麼**——不寫「貼上歸零」「短文歸零」「原可 +N」這類歸零與計分機制敘述（歸零狀態由「貼上／短文」狀態行呈現，解除後能拿回多少由補分清單的分數走向呈現）；**不用「＝」「→」等符號代替文字敘述**（「標題句近原樣出現在內文＝搬運非總結」要寫成「標題句幾乎原樣出現在內文，屬於搬運而不是總結」）；**評語一律中立、理性、客觀**——只陳述可查證的事實，不使用主觀評價或情緒性用語。分數與階梯完全不變。

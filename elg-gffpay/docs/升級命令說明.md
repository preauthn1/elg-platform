# 升級命令

當 CICD 在執行完 `app:migrate --silent` 命令後，將接續執行升級命令 `app:upgrade --silent` 同步數據。

目前同步的數據有
1. 新增遊戲商 `database/data/vendors.php`
2. 新增代理配置 `database/data/agent_setting_defines.php`
3. 更新 Stored Procedure (SP) `database/procedures`
4. 更新後台菜單 `database/data/agent_menu.php`

實作的方式則是調用以下命令
```sh
# 新增遊戲商
php artisan db:seed --class=SyncVendorSeeder
# 新增代理配置
php artisan db:seed --class=SyncAgentSettingDefinesSeeder
# 更新 Stored Procedure (SP)
php artisan db:seed --class=SyncProcedureSeeder
# 更新後台菜單
php artisan db:seed --class=SyncAgentMenuSeeder
```
